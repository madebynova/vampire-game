## Vampire Game 0.1.0 - first Windows build

The first standalone Windows build of the Vampire Game prototype. This is an **early development build**, not the finished game: one small greybox location (Blackthorn Estate), placeholder audio, no music.

### Download and play
1. Download **`VampireGame-Windows-v0.1.0.zip`** (below, under *Assets*).
2. Extract the whole zip to a folder.
3. Run **`VampireGame.exe`** and press **Play**.

Windows 10 or 11, 64-bit, and a graphics card with DirectX 12 or Vulkan support.

> **"Windows protected your PC"?** The game isn't code-signed yet. Click **More info -> Run anyway**. A SHA-256 checksum for the zip is attached to this release (`...zip.sha256`) if you want to verify it.

### What's in the prototype
Human <-> Vampire transformation, feeding (it plays differently on a sleeper, someone unaware, or a terrified victim), a 20-minute day/night cycle, deadly sunlight, Vampiric Sense, people who trust you and tell you things, Blood Memories, window and wall traversal for the Vampire form, two foxes, and a coffin that asks when you wake. Full list and controls: the [README](https://github.com/madebynova/vampire-game#readme).

### Your settings
Stored in `%APPDATA%\VampireGame`, outside the game folder, so replacing the game folder never loses them.

### Known limitations
- Controller support exists but has **not been tried on physical controllers**.
- Tested on a single machine (NVIDIA GTX 1660 SUPER); other hardware may differ.
- No save games yet (only settings), no music, greybox visuals, one small location.
- Not code-signed (see above).
