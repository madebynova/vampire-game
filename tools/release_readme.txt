VAMPIRE GAME  -  version {{VERSION}}  (Windows, 64-bit)
=====================================================

A third-person vampire PROTOTYPE. This is an early development build, not the finished game.

HOW TO PLAY
  1. Extract this whole zip to a folder (right-click > Extract All).
     Don't run it from inside the zip.
  2. Double-click VampireGame.exe.
  3. Press Play.

CONTROLS (keyboard and mouse; controllers are supported too)
  WASD move, mouse look, Shift run, Space jump
  E interact / feed (hold), F become Vampire / Human, Q Vampiric Sense
  Esc pause, H controls screen
  The in-game controls screen (H) always shows the real buttons for your device.

WINDOWS "PROTECTED YOUR PC" MESSAGE
  The game is not code-signed yet, so Windows SmartScreen may warn you the first time.
  Click "More info", then "Run anyway". The file's SHA-256 is published next to the
  download on the GitHub release page if you want to verify it.

YOUR SETTINGS
  Settings are stored in  %APPDATA%\VampireGame  (paste that into the Explorer address bar).
  They are kept OUTSIDE the game folder, so you can delete or replace the game folder
  (for example to update) without losing them.

REQUIREMENTS
  Windows 10 or 11, 64-bit, and a graphics card with DirectX 12 or Vulkan support.
  So far it has only been tested on one machine (NVIDIA GTX 1660 SUPER).
